주요 기능

밴픽을 더 똑똑하게

  • 카운터 분석

    상대 픽 기반으로 카운터 점수를 계산해 최적의 픽을 추천합니다.

  • 가중치 설정

    특정 영웅의 위협도를 직접 조절해 맞춤형 추천을 받을 수 있습니다.

  • 콤보 저장

    영웅별 스킬 콤보를 직접 입력하고 저장해두세요.

사용 방법

  • 1. 포지션 선택

    EXP, MID, 정글, GOLD, 로밍 중 내가 플레이할 포지션을 선택합니다.

  • 2. 상대 픽 입력

    상대 팀이 고른 영웅을 검색해서 슬롯에 추가합니다. 최대 5명까지 가능합니다.

  • 3. 추천 확인

    계산 버튼을 눌러 카운터 점수가 높은 영웅 추천 목록을 확인합니다.
